Unmodified clicks show a confirmation containing the actual destination; Cancel is the default. Local links are limited to the terminal workspace after canonicalization. A small image/text extension allowlist opens non-executable documents; scripts, bundles, other types and folders are revealed rather than launched. ## Repo Map — implementation history, not production promotion

This worktree replaces Changes with a **nested weighted treemap**, not the earlier 24-tile square grid. Folder frames enclose descendants; file weights use total physical text lines, separately from Git `+ / −`. All files are shown by default, with Only changes, folder/aggregate drill-down, Back/Root and full-inventory search. The map fits its pane without panning or canvas scrolling. Rendering is bounded to 2,000 nodes including folders/aggregates. Sibling order is stable, but size progress, inventory, filtering and viewport changes can reflow rectangles. Tiny files can be unlabeled slivers; search and keyboard navigation remain important.

The right-hand inspector starts closed, supports pointer/keyboard resizing and expand/restore within workspace content, and preserves map focus, reading mode and reader scroll across expansion. It stays side-by-side at 760×540; very small content widths use the full-content reader. Escape dismisses search before restoring/closing the reader or navigating back. Virtual rows replace the former 4,000-line display cutoff: every loaded bounded file/diff line is reachable. Staged/unstaged diffs, deleted-content provenance, five-second polling and version-sensitive temporary review acknowledgement remain. No persistent file-selection outline is added.

Text sizing and untracked/unborn counts share at most 64 contents per snapshot, four concurrent working-file jobs, 512 KiB per file and a two-second work-admission deadline (not a hard in-flight I/O timeout). Historical blobs share the budget. Focus hints are balanced with a fair cursor; the metadata/size cache is bounded to 100,000 entries and retains no source contents. Unknown/empty files use minimum layout weight 1 without claiming one measured line. Pending, unavailable and stale values remain explicit. Git counts compare HEAD to working tree rather than summing staged and unstaged edits. Inventory retains the 100,000-file and Git output/time limits; over-budget repositories fail visibly. See README for precise limits and non-transactional freshness caveats.

The implementation continuation added guarded hint-free snapshot retry when a selected untracked path disappears, compact reading-tab wrapping, bounded-read/cache regression coverage and delayed-response/recovery tests. This final verification pass changed **only native test synchronization/capture waits and documentation**: compact screenshots now await loaded diffs; the narrow-divider screenshot awaits map resize; the delayed-snapshot test waits for the automatic request it intentionally holds instead of blocking on a disabled Refresh button. No application code was changed in this pass.

Component Preview and Agent tracker remain **explicit unsupported/unconnected states**, not completed integrations. Preview links to the existing workspace browser. The tracker lists only separately labeled workspace terminals; no main/subagent event adapters, identities, task statuses, or file attribution are implemented.
