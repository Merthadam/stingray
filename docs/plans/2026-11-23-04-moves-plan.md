# 04 · Moves into the hexagonal layout Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

> **Execution rules (every plan of this PR):** the executor runs the plans sequentially, one plan at a time, in the
> order of [the index](2026-11-23-modular-restructure-plan.md). Every commit passes `npm run check`. Never edit or delete
> an existing test assertion except those the spec lists; every allowed test edit is recorded in
> `docs/plans/2026-11-23-test-edit-ledger.md` in the same commit. Branch: `chore/modular-restructure`. Do not push or open
> the PR before plan 10's last task. Never stage `release/`, `artifacts/`, `dist*/`, `node_modules/`.

**Goal:** every file moves to its final folder with `git mv` (history follows); the code-graph feature is renamed
`codegraph` → `stinggraph` in folder and file names; only import specifiers, build/test config and path strings change.
No behaviour change.

**Architecture:** behaviour-free commit. `electron/` gets `app/`, `core/<feature>/`, `adapters/{driving,driven}/`;
`src/` gets `app/`, `features/<feature>/`, `shared/`; pure cross-process code goes to `shared/views/`; tests go to
`tests/<feature>/`. Each core feature and each renderer feature gets an `index.ts` with named re-exports. In this commit
importers keep **direct file paths** (no switch to `index.ts` yet): the `git ↔ repo-map` and `repo-map ↔
repo-map-size` cycles would otherwise risk TDZ errors at startup; plans 05a-05h switch importers to `index.ts` while
removing those cycles, and plan 09 enforces it.

**Tech Stack:** git, TypeScript (`npm run typecheck` as the import fixer), esbuild, Vite, Playwright e2e.

**Spec:** [04 § Commit 4 — Moves](../specs/2026-11-23-04-hexagonal-modules-design.md#commit-4--moves); naming: umbrella "Feature name stinggraph".

**Depends on:** plan 03 committed. **Commit:** one, `refactor: move files into the hexagonal layout (git mv + paths only; codegraph feature renamed stinggraph)`.

**Never renamed:** the npm package `@colbymchenry/codegraph` and its imports, `.codegraph` dirs, `<userData>/codegraph/`,
the `codegraph.sharedBase` setting key, `dist-electron/codegraph-worker.cjs`, exported symbols (`createCodeGraphProcessHost`,
`serveCodeGraph`, `createCodeGraphHost`, `codegraphGrammarDir`, `excludeCodeGraphCache`, …), flat `window.stingray.*` names.
